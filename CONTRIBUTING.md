## Contributing

This project is open source, and we welcome contributions: adaptations/translations to different datasets, fixes to existing material, bug reports, and reviews of proposed changes are all welcome.

### Contributor Agreement

By contributing, you agree that we may redistribute your work under [our license](LICENSE.md). In exchange, we will address your issues and/or assess your change proposal as promptly as we can.

### How to Contribute

The easiest way to get started is to file an issue to tell us about a spelling mistake, some awkward wording, or a factual error. This is a good way to introduce yourself and to meet some of our community members.

1. If you do not have a GitHub account, you can contact a contributor via email. However, we will be able to respond more quickly if you use one of the other methods described below.

2. If you have a GitHub account, or are willing to create one, but do not know how to use Git, you can report problems or suggest improvements by [creating an issue](https://github.com/bayes-bats/tier2-freq-bayes/issues). This allows us to assign the item to someone and to respond to it in a threaded discussion.

3. If you are comfortable with Git, and would like to add or change material, you can submit a pull request (PR).

### Reporting Issues or Problems

If you encounter any issues or problems in using the materials, we recommend filing an [creating an issue](https://github.com/bayes-bats/tier2-freq-bayes/issues) on the repository. To do so, you must have a GitHub account. Filing issues is helpful, as it helps us document both past and present problems, and provides us a way to tie specific edits to the materials to individual issues.

Some examples of helpful issues to file are: spelling mistakes, ambiguities in language, or a mismatch between materials.

### Seek Support

To seek support with the materials, we recommend filing an [creating an issue](https://github.com/bayes-bats/tier2-freq-bayes/issues). This can be particularly helpful for other users; as other potential users may have the same question as you!
